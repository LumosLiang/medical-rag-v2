# Arctic 8K 与长窗口切分

2026-10-13，在固定 209 篇语料、50 道题上，长窗口方案将证据 Hit@5 从 0.82 提高到 0.84，Hit@10 从 0.86 提高到 0.94，MRR@10 从 0.593 提高到 0.686。三组各运行两轮，指标一致；新方案两轮的逐题首次证据排名也一致。应用和日常入库配置未切换。

## 实验设计

此前诊断发现，部分表格证据被 512 token 上限切散，另一些完整证据块虽能召回，却排在前五之后。本轮用 Snowflake 原生 Arctic Embed L v2.0 8K 同时验证模型变化和扩大上下文的效果。

| 组别 | 切分配置 | Embedding 模型 | 搜索服务，均位于 MEDRAG.CORE |
|---|---|---|---|
| 旧方案 | markdown_header_table_1200_200 | snowflake-arctic-embed-l-v2.0 | MEDICAL_CHUNKS_MARKDOWN_MULTI_INDEX_1200_200 |
| 仅换模型 | 同一批旧块 | snowflake-arctic-embed-l-v2.0-8k | MEDICAL_CHUNKS_MARKDOWN_8K_CONTROL |
| 长窗口方案 | structured_markdown_8k_body_1024 | snowflake-arctic-embed-l-v2.0-8k | MEDICAL_CHUNKS_STRUCTURED_MARKDOWN_8K_BODY_1024 |

三组保持相同 multi-index：chunk_text 和完整 section_path 参与关键词检索，chunk_text 参与向量检索。请求沿用此前最佳参数：texts / vectors / reranker 权重为 1 / 1 / 3，chunk_text / section_path 的 text_boosts 为 1 / 3。继续使用 Cortex Search 原生重排，没有添加外部重排。

语料快照为 corpus_2026_10_03，题集为 qset_v1，评分为 evidence_covered_v2，top-k=10。复用现有 LAYOUT 解析结果，不重新解析或修改题集。这里的 Hit@k 表示前 k 块中至少一块覆盖该题全部证据，不是标准 Recall@k；MRR@10 对前十无证据块的题记零。

## 最终切分配置

正文仍使用原生 Markdown header splitter，初切为 4096 字符、600 字符 overlap，超过 1024 tokens 再递归补切。1024 是正文上限目标，并不要求每块填满；章节边界仍会产生短块。

摘要单独保留，表格尽量整张保留，软预算为 8000 tokens，模型硬上限为 8192。表格放不下时复用原有按组、按行拆分及重复表头逻辑；极端超限继续递归兜底。紧邻且格式明确的表格脚注加入前缀。

参考文献仅按明确的 References / Bibliography / Literature Cited 边界过滤，版权和许可仅过滤明确行。摘要从前三页优先选择首个 Abstract，缺失时尝试 Summary，再尝试前两页具有方法、结果、结论标签的结构化摘要；关键词行结束摘要，正文 Summary 和重复 Abstract 不另算摘要。清理后重算全文字符范围，页号仍对应原 PDF。

这些选项存入 PIPELINE_CONFIG.method_options，复用现有协调过程与十参数接口；旧配置 options 为空时保持原行为。实现和处理边界见 [长窗口配置](../chunking.md)。

## 结论与边界

仅换模型没有提高 Hit@5 或 Hit@10。长窗口组合主要改善表格完整性、前十命中和首次证据排序，证明这批语料中的小窗口限制值得处理；但方法题下降，前五提升有限，不能得出“块越大越好”的结论。

主实验同时调整块尺寸、摘要保留、表格保留和噪声过滤，不能把全部提升单独归因于 embedding 窗口。qset_v1 已用于多轮调参，50 题上的提升尚未经过独立题集验证。评分采用词袋及数字匹配，不验证数值对应组别、比较符号或结论语义；本轮也没有评测生成质量。

应用仍使用旧服务，日常 ingest 仍使用 recursive_once_1200_200。新配置 inactive，本次只回填固定快照。后续应优先查看新方案仍在前五之外的证据块及下降题，区分保留信息与检索排序的作用，不直接继续扩大所有块。
