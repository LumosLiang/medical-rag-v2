## 已知边界

- EVAL 部分对象由 ACCOUNTADMIN 持有，snapshot 模块存在混合所有者；MEDRAG_ADMIN 无法访问或更新全部对象。此前按原所有者分别部署；独立 Git 入口整体待权限对齐后验收，不自动改 owner。
- 评分 v2 为词袋启发式，不验证比较符号或组别/数值对应关系。检索结果未记录 etag，覆盖重算读取实时 CHUNKS；比较前核对文件版本与服务刷新。
- 当前表格提取不保证续表合并、复杂表头及脚注关联；失败文件不自动重试；生成质量未正式评测。
